# Taskflow
*Flutter POA project - Abdel Hamid Saib - 2242417*

Een taak/gewoonte tracking applicatie gemaakt met Flutter en een .NET backend. 

Dit Project is gestard om Flutter te leren. De back-end en front-end zitten in apparte mappen, `FlutterFrontEnd` en `BackEndDotnet`. In de `Docs` folder zit documentatie voor het bijhouden van voortgang, architectuur keuzes en design. Deze documentatie is in Markdown en kan later gebruikt worden voor het schrijven van project documentatie en reflectie.
